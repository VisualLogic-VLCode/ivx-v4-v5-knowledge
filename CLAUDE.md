# Public Knowledge Runtime guardrails

- Use `npm run sync:source`; do not improvise an export by copying source directories.
- The maintenance checkout is not an end-user dependency and never enters Workflow configuration.
- Keep runtime cards, books, indexes, vocabularies, and provenance non-executable and free of raw case identities or credentials.
- Release signing uses the independent private key outside Git. Promote `knowledge-stable.json` only after the immutable Release assets are verified.
